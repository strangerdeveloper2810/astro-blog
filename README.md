# Freelance Dev Portfolio

Welcome to my personal portfolio built with [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/).
This project is designed to showcase my work, skills, and featured projects. It's open-source and optimized for performance, accessibility, and SEO.

## 🚀 Features

- 📱 **Responsive Design** — Mobile-first, fully responsive layout
- ⚡ **Fast & SEO-Friendly** — Optimized build with Open Graph tags, meta setup, and Lighthouse-perfect score
- 💻 **Pages Included** — Home, About, Featured, Now
- 🎨 **Fully Customizable** — Clean configuration and reusable components
- 📈 **Google Analytics Support** — Easily add tracking with your Measurement ID
- 🌍 **Ready for Deployment** — Works with [Vercel](https://vercel.com) or [Netlify](https://www.netlify.com)
- 🧠 **GitHub Stats Widget** — Supports OSS Insight's GitHub dashboard widget

## 🧑‍💻 Tech Stack

- Astro
- Tailwind CSS
- TypeScript
- React
- Vite / Rsbuild
- Markdown
- SVG Icons

## 📁 Pages Overview

- [`/`] Home — Developer intro + social links
- [`/about`] About — Career overview, interests, image, and contact
- [`/featured`] Featured — Articles, blog posts, and shoutouts
- [`/now`] Now — Current focus/projects

## 🛠 Local Setup

```bash
git clone https://github.com/strangerdeveloper2810/portfolio
cd portfolio
pnpm install
pnpm dev
```

## 📦 Build for Production

```bash
pnpm build
```

## 🌐 Deployment

Supports deployment to:
